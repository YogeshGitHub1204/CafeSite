Technical Architecture & IDE Implementation Blueprint

3D Specialty Cafe Commercial Website

A complete engineering specification for connecting a cafe's physical 3D aesthetic (interior architecture, lighting, materials, and downloaded 3D models) directly to live commercial ordering, 3D-synced table reservations, and an owner operations studio.

Frontend & 3D Engine

React 19 · TypeScript · Tailwind CSS v4 · Three.js (GLTFLoader + Draco + RoomEnvironment)

Backend & Persistence

Node.js · Express · REST APIs · PostgreSQL (Drizzle/Prisma) or Firestore / JSON Seed Store

Core Differentiator

Single source of truth linking 3D interior aesthetics & tables directly to live storefront commerce

1. Vision & Aesthetic-to-Commerce Connectivity

Most 3D websites treat WebGL as a decorative hero banner disconnected from revenue. In this architecture, the 3D Cafe Space IS the storefront interface:

1. Spatial Zone → Commercial Filter

Raycasting on 3D hotspots (Espresso Bar, Roastery Wall, Pastry Display, Retail Shelf) smoothly glides the camera to that station and filters the live ordering catalog to matching SKUs.

2. Physical 3D Tables → Live Reservations

Each physical table mesh (T1–T5) binds to a database table record. Pendant light warmth and coaster rings reflect live status (available, reserved, occupied). Clicking a 3D table pre-selects it in the booking engine.

3. Cafe Atmosphere ↔ Website Theme

Owner-selected atmosphere presets (Morning Limestone, Golden Hour, Evening Roastery) and material finishes (Limestone, Walnut, Slate, Brass, Obsidian) update 3D PBR materials/lighting and CSS storefront tokens simultaneously.

4. 3D Product Turntable → Variant Checkout

A secondary on-demand 3D turntable renders individual downloaded 3D products (cups, V60 drippers, pastries, bean bags), reflecting cup size or roast label variants in real time before checkout.

2. End-to-End System & User Flow

Both customer journeys and owner operations share the same unified state graph served by /api/state.

B. Pre-Import Asset Optimization Checklist (Run Before Putting in Repo)

Downloaded models from Sketchfab, BlenderKit, or TurboSquid are often 20–100 MB with 4K textures. Optimize them with gltf-transform CLI in your IDE terminal: 

# 1. Install gltf-transform globally or run via npx
npm install -g @gltf-transform/cli

# 2. Compress geometry with Draco + resize textures to max 1024px WebP
npx gltf-transform optimize input_machine.glb public/models/cafe/espresso_machine.glb \
  --compress draco \
  --texture-compress webp \
  --texture-size 1024

C. Drop-In TypeScript GLTFLoader + DRACOLoader + Auto-Grounding Utility

Create src/three/assetLoader.ts to load downloaded .glb models, normalize their scale and bottom-center pivot so nothing floats, enable shadows, and bind material hooks for aesthetic sync: 

import * as THREE from 'three';
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';
import { DRACOLoader } from 'three/addons/loaders/DRACOLoader.js';

const dracoLoader = new DRACOLoader();
// Host decoder files locally in public/draco/ to avoid external CDN failures
dracoLoader.setDecoderPath('/draco/');

const gltfLoader = new GLTFLoader();
gltfLoader.setDRACOLoader(dracoLoader);

export interface LoadedModelOptions {
  targetHeight?: number;
  castShadow?: boolean;
  receiveShadow?: boolean;
  onMaterialVisit?: (mat: THREE.MeshStandardMaterial, meshName: string) => void;
}

export async function loadNormalizedGLB(
  url: string,
  options: LoadedModelOptions = {}
): Promise<THREE.Group> {
  const gltf = await gltfLoader.loadAsync(url);
  const root = gltf.scene;

  // 1. Scale uniformly to real-world meter height if specified
  if (options.targetHeight) {
    const box = new THREE.Box3().setFromObject(root);
    const size = new THREE.Vector3();
    box.getSize(size);
    if (size.y > 0) {
      const scale = options.targetHeight / size.y;
      root.scale.setScalar(scale);
    }
  }

  // 2. Center X/Z and place bottom flush at Y = 0
  root.updateMatrixWorld(true);
  const alignedBox = new THREE.Box3().setFromObject(root);
  const center = new THREE.Vector3();
  alignedBox.getCenter(center);
  root.position.x -= center.x;
  root.position.z -= center.z;
  root.position.y -= alignedBox.min.y;

  // 3. Configure shadows and collect materials for dynamic theme sync
  root.traverse((child) => {
    if ((child as THREE.Mesh).isMesh) {
      const mesh = child as THREE.Mesh;
      mesh.castShadow = options.castShadow ?? true;
      mesh.receiveShadow = options.receiveShadow ?? true;
      if (options.onMaterialVisit && mesh.material instanceof THREE.MeshStandardMaterial) {
        options.onMaterialVisit(mesh.material, mesh.name);
      }
    }
  });

  return root;
}

D. Naming Convention inside Blender for Raycasting & Live Material Swaps

  • Name clickable parent nodes cleanly in Blender before export: hotspot_espresso, hotspot_roastery, table_T1 .. table_T5.
  • Name swappable materials consistently: mat_counter_stone, mat_wall_plaster, mat_accent_metal, mat_bag_label so applyAesthetics() can update downloaded .glb materials dynamically!
  • Always keep an invisible bounding-box proxy mesh on raycaster.layers.set(1) for complex .glb models so hover/click raycasting stays instantaneous.

Configure Express static middleware (or Cloudflare / Cloud CDN) to serve .glb, .wasm, and .jpg assets with immutable caching: Cache-Control: public, max-age=31536000, immutable and proper MIME type model/gltf-binary.

Infrastructure & Environment Checklist

  • DATABASE_URL pointing to managed PostgreSQL / Cloud SQL
  • ADMIN_AUTH_SECRET protecting Owner Studio APIs (PATCH /api/config, /api/menu, /api/orders/:id)
  • GET /api/health returning 200 OK + DB ping for Cloud Run / load balancer probes
  • Gzip / Brotli compression enabled on Express for JSON and .glb payloads
  • Automated daily database backup before menu/order volume scales

8. Step-by-Step IDE Integration Sequence for Your 3D Files

Follow these exact steps inside VS Code / Cursor to swap in your downloaded 3D assets cleanly:

  1. Inspect your downloaded files: Open them in Blender or gltf.report to verify scale (1 unit = 1 meter), check material names, and remove unseen backfaces.
  2. Compress with Draco: Run npx gltf-transform optimize into public/models/cafe/ and public/models/products/.
  3. Copy Draco decoders: Copy node_modules/three/examples/jsm/libs/draco/gltf/* into public/draco/ so loading never depends on third-party CDNs.
  4. Register models in cafeBuilder.ts & ProductShowcase3D.tsx: Call loadNormalizedGLB('/models/...') while keeping the existing procedural meshes as instant-render placeholders until the async Promise resolves.
  5. Verify in Browser: Run npm run dev, open Network tab (verify 200 OK on every .glb and .wasm), test clicking tables and hotspots, and test checkout & Owner Studio sync.
